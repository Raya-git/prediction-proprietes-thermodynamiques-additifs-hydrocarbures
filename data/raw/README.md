# Données brutes

Réserver ce dossier aux copies de travail non modifiées des données obtenues à partir de publications, de bases de données ou de mesures. Vérifier les droits de réutilisation avant dépôt. Les fichiers réels sont ignorés par Git par défaut ; documenter ici leur nom, leur provenance, leur date d’obtention et leur licence sans ajouter de contenu restreint.
