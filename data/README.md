# Données

Les données de ce projet concernent les propriétés thermodynamiques de substances pures et de mélanges servant d’additifs pour hydrocarbures. Garder les fichiers sources dans `raw/` et les extractions documentées dans `processed/`. Décrire la provenance, les unités, les conditions expérimentales et les traitements. Un modèle de tableau est disponible dans `templates/`.

Une première extraction de résultats publiés est disponible dans [`processed/yatim_2026_22MEE_enthalpie_exces.csv`](processed/yatim_2026_22MEE_enthalpie_exces.csv). Elle reprend les tableaux 5 et 6 d’un article en accès libre et concerne le mélange 22MEE + 1-butanol + éthanol. Ces valeurs proviennent de la littérature ; elles ne sont pas des mesures ni des prédictions produites par le présent projet.
