# Données

Les données de ce projet concernent les propriétés thermodynamiques de substances pures et de mélanges servant d’additifs pour hydrocarbures. Garder les fichiers sources dans `raw/` et les versions nettoyées ou calculées dans `processed/`. Décrire la provenance, les unités, les conditions expérimentales et les traitements. Un modèle de tableau est disponible dans `templates/`.
